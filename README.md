# fe-vue-css-starter

Vite + Vue 3 + TypeScript + plain CSS starter for DayZer0 frontend briefs.

## Stack

- Vite 6
- Vue 3 (`<script setup>`)
- TypeScript
- Plain CSS (scoped styles in `.vue` + global `src/style.css`)

## Getting started

```bash
npm install
npm run dev
```

Open the printed local URL — you should see **starter — it runs ✅**.

## Build

```bash
npm run build
```
